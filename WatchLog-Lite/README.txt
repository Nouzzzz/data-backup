WatchLog Fixed v20

Changes from v19:
- Added an editable TITLE / FILE NAME field to the details dialog.
- The edited title is saved to WatchLog and is used for future IMDb identification/search.
- Existing IMDb ID, rating, dates, notes and poster behavior are preserved.
- Clarification: this edits the stored WatchLog title/file-name text; it does not rename a real file on the computer.
- Changed the Save Changes button to green with a more rounded Material-style appearance.

Install:
1. Extract all files into the same folder.
2. Replace the previous index.html, style.css and app.js.
3. Hard refresh the browser with Ctrl+F5.
4. Open a title and edit TITLE / FILE NAME before using Identify if the imported title contains extra rating/date text.
